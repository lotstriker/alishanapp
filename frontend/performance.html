How to read the timings

Document wait includes the network and the HTML response. API server time covers the processing measured by Alishan. DB round trips include time waiting for and talking to PostgreSQL. API outside server is an estimate that can also include proxies and queuing. Page ready is measured after initial content rendering where available. A dash means the metric was unavailable or did not apply.
