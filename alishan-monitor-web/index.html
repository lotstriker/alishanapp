Dependency map

Alishan traffic flows from the app to Render APIs and then to Supabase. The scheduler and monitor observe that path separately.

  • Render app and APIsWaiting for app health checkFailure can affect page opening, server-side reads and saves.
  • Supabase databaseWaiting for monitoring history checkDatabase failure can affect records, payments and backup jobs.
  • Scheduled checksWaiting for scheduled historyFailure reduces monitoring coverage. App health needs separate evidence.
  • External sign-inDirect probe unavailableFailure can affect new sign-ins where the provider is enabled.
